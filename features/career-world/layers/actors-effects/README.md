# Actors and effects

The close-tier pedestrian subset is active for the authored NinjaOne project
towns and capital. Each pedestrian enters and exits through a retained
structure entrance while walking that town plan's existing closed pedestrian
loop, which is also the rendered local walkable-road source. Endpoint fades
hide the route repeat at the doorway. Reduced-motion presentation keeps the
same authored instances visible at deterministic interior points on their
routes instead of parking them in structure entrances.

Weather, particles, and sparse authored crash/foam accents remain deferred.
Base shoreline response remains ocean behavior.

# CI/CD · Round 1

## Research basis

A software delivery capability that responds to source changes with automated build, test, artifact production, staged promotion, deployment controls, feedback, and recoverable release paths.

- [Understanding GitHub Actions](https://docs.github.com/en/actions/get-started/understand-github-actions) — Official CI/CD workflow, event, job, step, and runner concepts.
- [Continuous deployment](https://docs.github.com/en/actions/get-started/continuous-deployment) — Official build, test, controlled deployment, and automation sequence.

Evidence boundary: Do not draw arrows, pipeline diagrams, brand-specific runners, logos, code, or deployment dashboards. Make sequence and gates physically legible.

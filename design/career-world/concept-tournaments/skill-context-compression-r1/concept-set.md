# Context compression · Round 1

## Research basis

A bounded-context capability that progressively reduces source material while preserving decision-relevant facts, authority, provenance, sequence state, and explicit repair or refresh paths when information becomes stale or incomplete.

- [Project walkthrough: ContextForge](../../../../docs/project-walkthrough-draft.md) — Repository-backed bounded context, bootstrap, delta, repair, refresh, resync, and evidence concepts.

Evidence boundary: Treat compression as selective preservation, not physical crushing or generic file compression. Do not render text, token counts, chat bubbles, or document pages.

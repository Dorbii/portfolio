## Research basis

A typed superset of JavaScript that performs static checking before execution, models JavaScript through structural typing and inference, supports strictness as an incremental spectrum, and erases types while preserving JavaScript runtime behavior.

- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro) — Static checking for JavaScript programs and the language's scope.
- [Type Compatibility](https://www.typescriptlang.org/docs/handbook/type-compatibility) — Structural typing based on members rather than nominal declarations.
- [TypeScript for New Programmers](https://www.typescriptlang.org/docs/handbook/typescript-from-scratch) — Typed JavaScript superset, pre-runtime checking, type erasure, and preserved runtime behavior.

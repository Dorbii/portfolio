# Career World Portfolio · Round 1

## Research basis

An interactive evidence-oriented portfolio world that maps employers, projects, and skills into a navigable 2.5D hierarchy using React, TypeScript, operator control, and explicit data contracts.

- [Career World production inventory](../../../../docs/career-world-production/asset-inventory.md) — Approved hierarchy and project-to-skill relationships.
- [Career World project art brief](../../../../docs/career-world-production/briefs/art-batch-c.json) — Accepted cartographer pavilion, viewpoint, courtyard, and evidence-gallery identity.

Evidence boundary: Do not render resume text, screenshots, labels, browser chrome, or invented evidence content.

## Generation method

- Generator: built-in OpenAI image generation
- Mode: fresh generation with no raster input
- Output target: one complete 1536 × 1024 concept per PNG
- Projection: orthographic true-isometric, approximately 225° azimuth and 35.264° elevation
- Style: exact-grayscale 2.5D wireframe architecture on a dark technical-grid field
- Hierarchy: supporting project landmark; below cities, above skills
- Postprocess: exact RGB grayscale and non-destructive fit to the standard canvas

# OpenAPI · Round 1

## Research basis

A language-agnostic machine-readable description of HTTP APIs that defines paths and operations, parameters and request bodies, reusable schemas, responses, security requirements, servers, and documentation or generation boundaries.

- [OpenAPI Specification](https://spec.openapis.org/oas/latest.html) — Official paths, operations, parameters, request bodies, schemas, responses, security, and tooling model.

Evidence boundary: Do not render YAML, JSON, endpoint text, HTTP verbs, Swagger or OpenAPI logos, code, or documentation pages. Use open portals and fitted contract volumes.

## Generation method

- Generator: built-in OpenAI image generation
- Mode: fresh generation with no raster input
- Output target: one complete 1536 × 1024 concept per PNG
- Projection: orthographic true-isometric, approximately 225° azimuth and 35.264° elevation
- Style: exact-grayscale 2.5D wireframe architecture on a dark technical-grid field
- Hierarchy: compact supporting skill building; below projects and cities
- Postprocess: exact RGB grayscale and non-destructive fit to the standard canvas

# Manifest V3 · Round 1

## Research basis

A Chrome extension platform contract that declares package metadata, permissions, content-script boundaries, event-driven service workers, host access, and remotely hosted code restrictions before an extension may operate.

- [Extensions Manifest V3](https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3) — Official manifest, service worker, permissions, content security, and remote-code constraints.

Evidence boundary: Do not render Chrome branding, puzzle pieces, browser UI, JSON, permission text, or version numerals. Express declaration and verification as tiered logistics architecture.

# Informatica · Round 1

## Research basis

A data integration capability in which source and target definitions are linked by mappings and transformation logic, then scheduled, validated, monitored, and governed as repeatable data flows.

- [Informatica Cloud Data Integration mappings](https://docs.informatica.com/content/dam/source/GUID-7/GUID-7E746072-6156-4FFE-9B7B-61EB6D588E15/64/en/CDI_November2024_Mappings_en.pdf) — Official source, target, transformation, mapping, and processing model.

Evidence boundary: Do not reproduce Informatica logos, UI, mapping diagrams, arrows, source names, or customer data. Keep source-transform-target flow physically connected and abstract.

- Generator: built-in OpenAI image generation
- Mode: fresh generation with no raster input
- Output target: one complete 1536 × 1024 concept per PNG
- Projection: orthographic true-isometric, approximately 225° azimuth and 35.264° elevation
- Style: exact-grayscale 2.5D wireframe architecture on a dark technical-grid field
- Hierarchy: compact supporting skill building; below projects and cities
- Postprocess: exact RGB grayscale and non-destructive fit to the standard canvas

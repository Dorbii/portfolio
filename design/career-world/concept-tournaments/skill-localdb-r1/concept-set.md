# LocalDB · Round 1

## Research basis

A developer-focused lightweight SQL Server Express capability that starts a minimal local database engine on connection, runs under the current user, supports automatic or private named instances, and stores application databases without full server administration.

- [SQL Server Express LocalDB](https://learn.microsoft.com/en-us/sql/database-engine/configure-windows/sql-server-express-localdb?view=sql-server-ver17) — Official minimal files, automatic startup, user context, instance types, and local storage behavior.

Evidence boundary: Do not depict a full data center, SQL logo, server rack, code, or database cylinder cliché. Keep the asset compact, private, local, and partially embedded.

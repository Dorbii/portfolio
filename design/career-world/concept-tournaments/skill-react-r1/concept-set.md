# React · Round 1

## Research basis

A declarative user-interface capability built from reusable components, composition, props, state, one-way data flow, shared state ownership, lifecycle synchronization, and reusable hooks.

- [Describing the UI](https://react.dev/learn/describing-the-ui) — Official component, composition, props, conditional rendering, and list concepts.
- [Sharing state between components](https://react.dev/learn/sharing-state-between-components) — Official shared-state ownership and one-way data flow.

Evidence boundary: Do not depict an atom, orbital rings, React logo, screens, UI panels, code, or browser chrome. Use component terraces and shared central state nonliterally.

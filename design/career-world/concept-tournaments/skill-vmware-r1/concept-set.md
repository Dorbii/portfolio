# VMware · Round 1

## Research basis

A virtual infrastructure capability in which ESXi abstracts physical compute, memory, storage, and devices into managed virtual machines, while vCenter organizes lifecycle, resource pools, placement, snapshots, migration, and shared capacity.

- [Broadcom VMware virtual-machine resource guidance](https://knowledge.broadcom.com/external/article/438023) — Official ESXi virtual CPU, memory, topology, and physical-host relationship.
- [Broadcom resource-pool guidance](https://knowledge.broadcom.com/external/article/381106) — Official vSphere virtual-machine grouping and shared resource allocation context.

Evidence boundary: Do not use VMware logos, product UI, literal server racks, nested squares copied from branding, or hardware diagrams. Preserve the abstract virtual-over-physical relationship.

## Research basis

A statically typed language and platform compiled to portable class-file bytecode for the Java Virtual Machine, with class loading, verification, linking, managed runtime data areas, threads, garbage collection, modules, and a deep standard ecosystem.

- [Java Virtual Machine Specification](https://docs.oracle.com/en/java/javase/26/docs/specs/jvms/index.html) — Class files, bytecode, runtime data areas, verification, loading, linking, modules, and execution.
- [JLS Execution](https://docs.oracle.com/en/java/javase/26/docs/specs/jls/jls-12.html) — Class loading, linking, initialization, execution, and program lifecycle.

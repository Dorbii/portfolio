# Career World concept sources

Career World art is isolated in three non-runtime source roots:

- `design/career-world/concepts/` contains the exact 56 manifest ID/path pairs that define canonical closure, plus 10 historical tracer and rejected-tracer records.
- `design/career-world/rejected-candidates/` is reserved for byte-identical archives of noncanonical failed candidates.
- `design/career-world/correction-candidates/` is reserved for noncanonical correction candidates awaiting independent QA and explicit promotion.

The rejected and correction roots require separate exact inventories and never count toward, satisfy, or replace the exact-56 canonical closure.

The earlier code-native-only runtime rule is superseded for the active 2.5D site. Runtime code must never serve the large design boards directly, but it may use deterministic, optimized derivatives of promoted canonical panels. Those derivatives live under `public/career-world/art/`, are generated by `scripts/build-career-world-runtime-art.ps1`, and preserve the approved artwork instead of retracing it as simplified geometry. Rejected and correction-candidate files remain prohibited.

The world backdrop is a narrow recorded exception: the independently approved `concepts/tracer/world-career-world-v1.png` supplies the locked one-mainland-plus-two-lower-islands topology. Entity artwork still resolves only from the promoted canonical 56-file inventory.

The current working tree contains 66 PNGs under the canonical/tracer root, totaling 139245462 bytes, and no PNGs yet under either candidate root. Three scoped root `.gitattributes` rules make every current or planned PNG Git LFS-managed when staged without altering its working-tree image bytes.

For a code-only clone that leaves LFS pointers in place:

```powershell
$env:GIT_LFS_SKIP_SMUDGE = '1'
git clone https://github.com/Dorbii/portfolio.git C:\tmp\portfolio-code-only
Remove-Item Env:GIT_LFS_SKIP_SMUDGE
```

Fetch all design-source pixels only when art, archive, or trace review needs them:

```powershell
git -C C:\tmp\portfolio-code-only lfs pull --include="design/career-world/concepts/**,design/career-world/rejected-candidates/**,design/career-world/correction-candidates/**" --exclude=""
```

Local LFS routing is configured, but remote authentication, quota availability, object upload, and clean-room retrieval remain unverified. Source preservation is not complete until an authorized push succeeds and a fresh selective pull verifies the committed LFS objects.
